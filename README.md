## 功能一覽

- **① 認識經緯線**:拖曳/方向鍵旋轉、點擊讀座標、3D→平面地圖展開、半球與緯度帶圖層(自動圖例)。
- **② 看見時間流動**:晨昏線、24 時區當地時間、城市時鐘、依日期上色;季節可切換春秋分、夏至、冬至。
- **③ 東加西減演練**:先猜再揭曉、四步驟解題、兩個方向比較、🎲 隨機出題。
- **④ 由時間找經度**:給兩地時間(或「某地正是中午」),先算時差、換成經度,再到地圖上點出位置;答對顯示正確時區與城市,答錯會告訴你那個位置的時間會是幾點。
- **老師模式**(右上角):鎖定圖層、大字(投影用)、各模式的「課堂預設」一鍵切換。
- **鍵盤**:方向鍵旋轉;模式②用 ← → 調時間、空白鍵播放/暫停。

## 內嵌的函式庫(vendor/)

d3 7.9.0、topojson-client 3.1.0、world-atlas 2.0.2(countries-110m)。

## 教學上的假設

- 預設太陽直射赤道(春分、秋分);夏至、冬至時直射 23.5°N / 23.5°S,晨昏線不再通過兩極。
- 時間皆為標準時間,不考慮日光節約時間。
- 時區以標準經線(0°、15°、30°…)為中心、左右各 7.5°。
- 東西半球:20°W 以東到 160°E 為東半球(康軒版)。
